# AirSon Agri Foods — Multi-page Website Starter

Responsive static website for the planned AirSon Agri Foods groundnut processing project in Gujarat.

## Pages
- `index.html` — Home
- `about.html` — About Us
- `facility.html` — Processing Facility
- `products.html` — Product categories
- `quality.html` — Quality & Food Safety
- `supply-exports.html` — B2B Supply & Exports
- `gallery.html` — Gallery
- `location.html` — Location
- `contact.html` — Contact form

## Run locally
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Open `index.html` in Chrome, or install the Live Server extension and select **Open with Live Server**.
4. Navigate between pages using the top menu.

## Before publishing
- Replace stock images with real company/site/product photos where possible, and ensure image licences permit your use.
- Add verified company email, phone/WhatsApp, final address, and any social media links.
- In `js/script.js`, replace `REPLACE-WITH-YOUR-EMAIL@example.com` with the business email. Until then, the form will validate fields but will not send/store enquiries.
- Confirm every process, product, capacity, certification, and commercial claim. The plant is currently described as in the planning stage.
- The 5 TPH figure should only be described as a planned design target if that is accurate for the current project.
- The current form opens an email draft using `mailto:` after configuration. It does not automatically send messages or store data in a database.
- Images and Google Fonts are loaded from external services and require an internet connection. Replace with locally stored licensed assets if preferred.

## Publish with GitHub Pages
1. Create a GitHub account and a new repository.
2. Upload the contents of this folder. Keep `index.html` in the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
5. Wait for deployment and open the URL GitHub provides.
6. Purchase your custom domain after you are satisfied with the site. Add it under Pages settings and follow the DNS instructions provided by your registrar/GitHub.

This is a static website. A backend/database is needed for automatic enquiry storage, customer accounts, online orders, payments or an admin panel.
